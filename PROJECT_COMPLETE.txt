                         HOW TO USE THE SYSTEM
================================================================================

1. BROWSE BARBERS (Customer View)
   curl -H "Authorization: Bearer API_KEY" \
     http://100.84.100.96:5000/api/barbers

2. VIEW COMPANY DASHBOARD (Company Owner)
   curl -H "Authorization: Bearer API_KEY" \
     http://100.84.100.96:5000/api/v1/company/dashboard

3. CREATE NEW COMPANY (Admin)
   curl -X POST http://100.84.100.96:5000/admin/companies \
     -H "Authorization: Bearer ADMIN_KEY" \
     -H "X-Admin-Role: true" \
     -d '{"name":"Barbershop","owner_email":"owner@example.com"}'

4. CLONE TENANT DATABASE (Admin)
   psql -U postgres -c \
     "CREATE DATABASE foundation_barber_2 TEMPLATE barber_app_template"
