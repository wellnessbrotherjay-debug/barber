# ios/ — Capacitor iOS shell

Native iOS wrapper generated by Capacitor (`capacitor.config.ts` at repo root). The web bundle is built with the production API URL and copied in by `npm run build:ios` (`vite build` + `npx cap sync ios`).

| Path | Purpose |
|---|---|
| `App/` | The Xcode project/workspace: `App.xcodeproj`, Info.plist (permission usage strings for location/camera/photo library — required or the app crashes on first use), app icon, safe-area/Dynamic Island layout fixes |
| `capacitor-cordova-ios-plugins/` | Generated Cordova plugin shims (do not edit by hand) |
| `debug.xcconfig` | Debug build settings |

Workflow: `npm run build:ios`, then open `ios/App/App.xcworkspace` in Xcode to run on simulator/device or archive for App Store. App Store compliance work (account deletion, legal pages, permissions) is documented in `docs/SCOPE_RECONCILIATION.md` §A2. Android shell is not yet generated (outstanding, clause 3.1(a)).
